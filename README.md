Лабораторна робота 3: Складання програм циклічної структури

Опис проєкту
Отримати навички побудови алгоритмів циклічної структури за допомогою операторів
while та for. Проєкт включає реалізацію базових циклів, вкладених структур для
імітації відліку часу, маніпуляції з масивами даних та табулювання математичних
функцій з аналізом результатів.

Архітектура
src
├── Task1.java # Базові цикли (for/while)
├── Task2.java # Вкладені цикли (h/min)
├── Task3.java # Синхронний відлік (h/min/sec)
├── Task4.java # Робота з масивами
└── Task5.java # Табулювання та фільтрація

Завдання
1. Повторення фрази:
     Вивести фразу "Java – це цікаво!" 50 разів циклом for.
     Вивести ту саму фразу 50 разів циклом while.
2. Імітація часу (години та хвилини):
     Використовуючи вкладений цикл for, вивести послідовність від 0 h 0 min до
     2 h 59 min.
     Реалізувати ідентичну логіку за допомогою циклу while.
3. Синхронний таймер:
     Використовуючи цикл while, реалізувати синхронний відлік годин, хвилин
     та секунд до 3-х годин.
4. Обробка масивів:
     Створення масивів парних/непарних чисел (по 50 елементів).
     Виведення елементів за непарними індексами та у зворотному порядку.
     Зміна знаку для непарних елементів масиву.
5. Математичне табулювання:
     Табулювання функції f(x) = 3x - 4sin(x2) на відрізку [0; 4] з кроком 0.2 .
     Пошук кількості значень функції у заданому користувачем діапазоні.

Встановлення та запуск
Компіляція
cd Lab3
javac -d bin src/*.java

Виконання
java -cp bin Task1
java -cp bin Task2
java -cp bin Task3
java -cp bin Task4
java -cp bin Task5
